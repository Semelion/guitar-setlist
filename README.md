# На струнах

Гитарный сетлист для совместного вечера: каталог из 291 песни, очередь исполнения, интерактивные комнаты для гостей, голосование, музыкальный квиз и встроенный редактор аккордов.

Основной вариант поставки — полностью статическое одностраничное веб-приложение React/Vite для GitHub Pages с P2P-синхронизацией через PeerJS (WebRTC). Дополнительно сохранена серверная сборка vinext/Cloudflare Worker.

## Основные возможности

- **Комнаты без пароля**: Создание и вход в комнату не требуют паролей или регистрации. Ведущий генерирует случайный код или задаёт собственный; права ведущего сохраняются локально в браузере (`localStorage`). Гость присоединяется по короткому коду или прямой ссылке.
- **Именованные гости**: Каждый участник указывает своё имя, которое сохраняется в браузере и используется для предложений песен, голосования, участия в квизе и таблицы лидеров.
- **Предложения песен**: Гости могут предлагать ведущему песни как из готового каталога (291 песня), так и добавлять свои варианты со ссылкой на текст и аккорды. Ведущий просматривает предложения, принимает их в библиотеку и очередь либо отклоняет.
- **Голосование за следующий трек**: Ведущий открывает голосование перед раундом; зрители выбирают понравившиеся треки из сформированного пула.
- **Музыкальный квиз (20 секунд)**:
  - Формируется при наличии голосов минимум за 3 разные песни (победившая песня + 2 альтернативы).
  - Подготовка трека открывает встроенные аккорды для ведущего, а квиз стартует по явной кнопке «Начать играть · Квиз 20 секунд».
  - Скрытие ответа: название текущей песни, очередь и распределение голосов скрыты от зрителей до истечения 20-секундного таймера.
  - Ответы фиксируются по времени получения ведущим; за верный ответ начисляется 1 балл.
  - По окончании таймера раскрываются правильный ответ, результаты голосования и обновленный рейтинг.
- **Рейтинг и таблица лидеров**: Динамический лидерборд участников с отображением набранных баллов в реальном времени.
- **Внутренний редактор аккордов**: Встроенный просмотрщик и редактор текста с аккордами для ведущего. Позволяет сохранить и быстро открыть аккорды к песне локально в браузере, без зависимости от встраивания сторонних сайтов. Текст добавляется вручную: автоматический импорт из каталогов не реализован.
- **Синхронизация через PeerJS (WebRTC)**: Прямой обмен состоянием комнаты и командами между браузерами через WebRTC DataConnections (сигналинг через `0.peerjs.com:443`). **Внимание**: браузерная вкладка ведущего является источником истины и должна оставаться открытой и подключённой к сети во время вечера.
- **CSV и localStorage**: Библиотека песен, порядок очереди, локальные аккорды и состояние сессии сохраняются в `localStorage`. Доступен экспорт полной библиотеки в файл CSV с поддержкой Unicode/BOM.

## Быстрый запуск

Требуется Node.js >=22.13.0.

```sh
npm ci
npm run dev:static
```

Откройте локальный адрес, выведенный Vite в терминале.

### Сборка статической версии для GitHub Pages

```sh
npm run build:static
npm run preview:static
```

Статические артефакты компилируются в директорию `dist-static/`.

## Архитектура и хранение

- `static/peer-transport.ts` — P2P-транспорт на базе PeerJS (WebRTC DataConnection), сквозная передача команд гостей с Transport ACK, устойчивость к смене epoch/F5 ведущего и локальный фоллбек через `BroadcastChannel` для вкладок одного браузера.
- `static/room-client.ts` — клиентские обёртки создания паблишера, вьюера и очередей отправки/приёма команд.
- `static/room-core.ts` — чистые редьюсеры состояния комнаты, генерация идентификаторов, валидация команд, подсчёт очков и скрытие ответа до завершения квиза.
- `static/host-state.ts` & `static/host-library.ts` — управление жизненным циклом раундов ведущего (голосование -> подготовка -> квиз 20с -> раскрытие) и интеграция с библиотекой.
- `lib/chords.ts` — локальное персистентное хранилище текстов и аккордов песен ведущего в `localStorage`.
- `static/admin-shell.tsx` — панель управления ведущего, управление квизом, аккордами и комнатой.
- `static/viewer.tsx` — адаптивный интерфейс зрителя (предложение песен, голосование, карточка квиза 20с, итоги и рейтинг).
- `static/gate.tsx` — стартовый экран входа в комнату (для гостя и ведущего).
- `lib/core.ts` — модель песен, парсер/генератор CSV, правила очередей и переходов.

## Проверка качества и тесты

```sh
npm test
npx tsc --noEmit
npm run build:static
```

Автоматические тесты охватывают:
- Парсинг и сохранение CSV (включая кавычки, переносы строк, кириллицу).
- Жизненный цикл сетлиста, перемещение и приоритизацию песен в очереди.
- Логику квиза (скрытие ответа, дедупликацию ответов, 20-секундный таймер, подсчёт рейтинга).
- Восстановление состояния после перезагрузки страницы (F5) без повторного начисления очков.
- P2P-транспорт на эмуляторе соединений PeerJS.
